# DeepSeek Kit v0.19.3

**First public beta release.**

DeepSeek Kit is an independent Chromium browser extension that adds reusable prompts, lightweight local memory, snippets, code-block tools, interactive question forms, charts, and sandboxed widgets to DeepSeek Chat.

## Highlights

- **Prompts and memory:** reusable scheduled prompts, local notes, and per-message context controls.
- **Slash snippets:** searchable snippets inserted directly into the DeepSeek composer.
- **Code tools:** collapse long blocks, optional line numbers, Markdown preview, and ZIP export for code blocks.
- **Interactive questions:** single-choice, multiple-choice, and free-text forms generated from supported `ask` blocks.
- **Charts and widgets:** SVG charts and interactive HTML widgets in sandboxed iframes.
- **Composer helpers:** list continuation with Shift+Enter and optional reasoning-block folding.
- **Reliability and isolation:** widget sandbox hardening, required Chromium E2E coverage, and safer send acknowledgement handling to avoid duplicate submissions.

## Install

1. Download `DeepSeek-Kit-0.19.3.zip` from the Assets section below.
2. Extract the ZIP.
3. Open `chrome://extensions` in Chrome, Edge, or Brave.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose the extracted `DeepSeek-Kit-0.19.3` folder containing `manifest.json`.
6. Open [DeepSeek Chat](https://chat.deepseek.com/).

The extension targets Chrome 105+ and Chromium-based browsers. It is not currently distributed through the Chrome Web Store.

## Important limitations

- DeepSeek Kit is independent and is not affiliated with or endorsed by DeepSeek.
- It relies on DeepSeek Chat's page structure. Changes to the site can temporarily break features.
- Hidden mode can submit messages on your behalf. If a send cannot be confirmed, check the chat before trying again.
- Generated widgets are untrusted code. Their iframe sandbox and Content Security Policy isolate them from the DeepSeek page and block common network mechanisms, but the iframe can still navigate itself to another URL. Do not run widgets containing sensitive information; disable widget rendering under **Settings → Visuals** when you cannot inspect the code first.
- The extension has not been exhaustively tested against every live DeepSeek interface variant.

## Privacy

The extension stores its settings, prompts, memories, and snippets in the browser's local extension storage. Its core code does not send this data to a Kit-operated server. Review the repository README and source for full details.

This is an early public beta. Bug reports and compatibility feedback are welcome.
