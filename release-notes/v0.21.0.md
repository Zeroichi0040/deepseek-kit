# DeepSeek Kit v0.21.0

A drawer organization and editing update.

## Changes

- **Categories:** Organize prompts, memory notes and snippets in collapsible custom categories. Collapse states persist; deleting a category moves its contents to General.
- **Dedicated editors:** Create and edit items in a consistent editor without expanding the list. Cancelling a new item does not create an empty entry.
- **Prompt drag-and-drop:** Insert prompts before or after other prompts or move them between categories. Visual ordering is independent of injection order.
- **Memory and snippets:** Consistent dashed New buttons, a token budget information icon, and a simplified Use memory toggle.
- **Compatibility:** Existing saved items remain available, and the new organization metadata is preserved in backups.

## Install

1. Download `DeepSeek-Kit-0.21.0.zip` from the Assets section below.
2. Extract the ZIP.
3. Open `chrome://extensions` in Chrome, Edge, or Brave.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose the extracted `DeepSeek-Kit-0.21.0` folder containing `manifest.json`.
6. Open [DeepSeek Chat](https://chat.deepseek.com/).
