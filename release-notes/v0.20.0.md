# DeepSeek Kit v0.20.0

A settings and code-block usability update.

## Changes

- **Simpler question-form settings:** Question forms are now always rendered while DeepSeek Kit is enabled. The built-in Questions prompt remains independently configurable under Prompts, and **Send answers straight away** now lives under Settings → Messages.
- **Always collapse:** Automatically fold every code block with an available Expand control, regardless of its length. The existing long-block threshold remains configurable when Always collapse is off.
- **Editable collapse threshold:** Change the number of lines before automatic collapsing directly under Settings → Code blocks.
- **More reliable collapse behavior:** Manual fold choices are preserved during the page session, blocks are never left folded without an available Expand control, and collapse settings correctly reapply when toggled or when code-block tools are restored.
- **Settings migration and input validation:** Remove the obsolete question-form setting from saved profiles and correctly clamp a zero line threshold to the minimum.

See the [v0.19.3 notes](v0.19.3.md) for installation steps and known limitations.
